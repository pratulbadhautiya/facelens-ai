# FaceLens AI — Face Intelligence Studio

A privacy-focused face detection web application built by Pratul Badhautiya.

## Live Application

https://facelens-ai.hatchable.site

## Features

- Face detection in uploaded images
- Real-time face detection using a device camera
- Facial landmark detection
- Detection confidence scores
- Adjustable detection thresholds
- Face bounding boxes and landmark overlays
- JSON export and snapshots
- Recent analysis history
- Privacy-focused browser-side image analysis

## Tech Stack

- HTML5
- CSS3
- JavaScript
- face-api.js
- Hatchable hosting

## Privacy

FaceLens AI is designed to process camera frames and selected media in the browser. It does not identify individuals or establish their identity.
